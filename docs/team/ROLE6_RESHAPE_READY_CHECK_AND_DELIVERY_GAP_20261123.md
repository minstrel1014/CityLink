## One new defect worth carrying forward: F12

Role 6 found a defect in its own normalization contract while testing it: in `regexp_replace(src,'--.*','','g')` the `.` matches newlines, so the comment-stripping rule silently deletes everything after the first `--` in a function body, producing a stable but wrong digest. The shipped rule uses flags `gn`, plus a fifth `btrim` rule. This is exactly the class of error the real-parser gate exists to catch, and it is the second self-caught defect in this track after the F10 `head -2` truncation.
